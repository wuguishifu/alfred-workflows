# plus-addressing

> Note: this repo is deprecated and has moved to https://github.com/wuguishifu/alfred-workflows.

This is an alfred workflow that uses `+` keyword to generate a plus address email. You can configure it with whatever base email you want to use, such as `bo@wuguishifu.dev` and then when you use the `+` alfred workflow shortcut it will generate a plus address email with the current timestamp in YYYYMMDDhhmmss format.

An example: `bo+20251128125525@wuguishifu.dev`.
